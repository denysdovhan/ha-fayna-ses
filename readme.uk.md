# Файна СЕС для Home Assistant

Моніторинг електростанцій через публічні посилання [Файної СЕС](https://fayna-ses.funs.net.ua/). Інтеграція лише читає дані та не керує обладнанням.

## Встановлення

Потрібен Home Assistant 2026.2.3 або новіший. Інтеграцію ще не опубліковано в стандартному каталозі HACS.

1. Скопіюйте `custom_components/fayna_ses` у `config/custom_components` Home Assistant.
2. Перезапустіть Home Assistant.
3. Відкрийте **Налаштування → Пристрої та служби → Додати інтеграцію → Fayna SES**.
4. Вставте посилання `https://fayna-ses.funs.net.ua/s/<ідентифікатор-станції>`.

Кожна електростанція має окремий пристрій і запис інтеграції. Повторне додавання тієї самої станції блокується. Обліковий запис не потрібен.

## Особливості

Опитування відбувається щохвилини, вимірювання зазвичай оновлюються приблизно раз на п'ять хвилин. Телеметрія стає недоступною, якщо час джерела чи вимірювання відсутній або старший за 30 хвилин. Зв'язок перевіряється лише за часом джерела: актуальний статус офлайн залишається видимим, навіть коли вимірювання припинились. Останній час і статус залишаються видимими за успішного запиту. Помилки мережі чи формату роблять усі сутності недоступними; інтеграція повторює запити автоматично.

Зв'язок означає доступність телеметрії, а не наявність міської електромережі. Відсутні значення не замінюються нулями. Стан акумулятора має зону спокою ±20 Вт; джерело живлення визначається евристикою сайту з порогом 50 Вт. Ці ознаки не гарантують визначення відключень.

Добові лічильники скидаються опівночі за Києвом і допускають виправлення постачальника. Облік імпорту й експорту в добовій енергії мережі не задокументований. Історичне завантаження, місячні підсумки та керування не реалізовані. API публічний, але незадокументований; його формат може змінитися. Локальна іконка потребує HA 2026.3+. Додаткових залежностей, власних дій, тригерів чи умов немає — використовуйте стандартні засоби автоматизації HA.

## Видалення

У **Налаштування → Пристрої та служби → Fayna SES** відкрийте меню станції та виберіть **Видалити**. Після видалення всіх записів можна прибрати каталог `config/custom_components/fayna_ses` і перезапустити HA.

## Розробка

`scripts/bootstrap` встановлює середовище; `scripts/lint` перевіряє код, `scripts/test` запускає тести, `scripts/develop` запускає локальний HA. Перевірка на реальному встановленні HA залишається ручним кроком.
